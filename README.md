# 📊 Tableau Dashboards

Interactive Tableau workbooks that turn raw CSV data into visual stories.

| Workbook | Description | Key metrics |
|---|---|---|
| **Covid in Canada** | Tracks the spread and impact of COVID-19 across Canadian provinces | Cases, deaths, mortality rate, 7- and 14-day averages, incidence rate |
| **Megastore** | Sales performance analysis for a retail store | Sales amount by product category and by salesperson |
| **Career Track** | Analysis of student enrolment and completion across learning career tracks | Completion rate, enrolment over time, track comparison |

## How to view
Open the `.twb` files in [Tableau Public](https://public.tableau.com/) (free) or Tableau Desktop.
